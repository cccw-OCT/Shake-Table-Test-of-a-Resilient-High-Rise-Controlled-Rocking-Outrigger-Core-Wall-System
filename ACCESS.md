# Access, Citation, And Reuse Notes

This repository contains experimental database files for Trial-1. The dataset
includes raw measurements, design and construction documents, instrumentation
records, photos, and videos.

## Access Notes

- Large files are stored with Git LFS.
- A complete local copy requires both Git and Git LFS.
- Users should verify that LFS files are downloaded before opening spreadsheets,
  photos, videos, or document files.

## Recommended Citation Template

When citing this dataset, include:

```text
Trial-1 Experimental Database, cccw-OCT/Trial-1, version or commit hash,
accessed YYYY-MM-DD.
```

For a precise citation, include the Git commit:

```powershell
git rev-parse HEAD
```

## Redistribution

Before redistributing the dataset, confirm the applicable project, institution,
and collaborator permissions. If a formal license is required, add a `LICENSE`
file to the repository root.
